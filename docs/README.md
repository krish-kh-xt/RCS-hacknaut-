# docs

**Purpose:** documentation and presentation material for RCS (Hacknauts 2.0).

## Setup
Nothing to install. Open the Markdown files in VS Code and the deck in PowerPoint.

## Environment variables
None.

## Folder guide
- `RCS_Hacknauts2_0.pptx`: the presentation for the judges
- `architecture.png`: system diagram (traveller app, backend, database, worker, SMS gateway, dashboard)
- `api.md`: the fixed API contract, kept in sync with the backend
- `demo-script.md`: step-by-step demo with what to say and fixes for common problems

Keep the deck and `api.md` up to date with what is actually built. If the contract changes, update `api.md` first and tell the team.
